# Windows 11 Help Desk Lab

## Project Overview

This repository documents my hands-on Windows 11 help desk training in a virtual lab environment. The project is designed to develop practical skills for entry-level Help Desk, Service Desk, Desktop Support, and IT Support positions.

All users, organizations, and support incidents in this lab are fictional.

## Lab Environment

- Host computer: 2019 Intel MacBook Pro
- Host memory: 16 GB RAM
- Virtualization software: Oracle VirtualBox
- Guest operating system: Windows 11 Enterprise Evaluation
- Virtual workstation name: HELPDESK-PC01

## Repository Sections

- **Lessons:** Guided exercises and learning notes
- **Screenshots:** Evidence of configurations and troubleshooting
- **Tickets:** Simulated service desk ticket documentation
- **Knowledge Base:** Step-by-step support articles
- **Scripts:** PowerShell tools created during the lab
